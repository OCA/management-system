This module adds an Information Security Management System (ISMS)
application within Odoo. It installs the documentation, feared events,
and action tools required to deploy and manage an ISMS aligned with ISO
27001.

Before installing, define the scope of your system and perform a
security analysis. Methods such as EBIOS can help with risk analysis,
evaluation, and treatment.

Configuration
=============

To configure your ISMS:

- Go to Management Systems > Configuration and define asset categories
  and threat sources
- Go to Management Systems > Documentation > Manuals and define primary
  and supporting assets, vectors, feared events, controls, and work
  instructions
- Customize the Information Security Manual template under Manuals

Usage
=====

To use your ISMS:

- Plan audits and top management reviews
- Manage nonconformities and improvement actions
- Link security controls to actions from the Security Controls tab on
  each action
