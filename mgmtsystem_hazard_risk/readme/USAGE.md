To use this module, you need to:

- go to **Management Systems** \> **Manuals** \> **Hazard**
- create or open a hazard and select a **Risk Type**
- on the **Risk Evaluation** tab, set probability, severity, and usage; the
  **Risk** score is computed from the company formula
- on **Residual Risk Evaluations**, record follow-up assessments after control
  measures are in place
